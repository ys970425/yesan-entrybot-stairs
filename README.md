# 예산과 함께하는 엔트리봇 무한의 계단

예산 엔트리 쉼터 부스용 태블릿 게임입니다. 제작: myoLab(산쌤)

- 플레이: https://ys970425.github.io/yesan-entrybot-stairs/
- 조작: 왼쪽 버튼(←) = 방향 바꾸기, 오른쪽 버튼(→) = 오르기. 화면을 누르면 더 가까운 버튼으로 인식
- 버튼 위치: 처음 화면 "버튼 위치 바꾸기"에서 두 버튼을 끌어 옮김 (태블릿에 저장, "원래대로"로 초기화)
- 글자 모으기: 계단 위 사과 글자 "엔트리와 예산사랑"을 모음 (무작위·중복 있음, 이미 모은 글자는 효과 없음, 보통 100~150계단에 완성)
- 부스터: 8글자를 다 모으면 자동으로 5초 동안 켜짐. 계단이 일직선, 화면 아무 곳이나 터치하거나 스페이스바 연타로 오름
- 배경: 100계단마다 예산 명소 9곳 (충의사 포함), 900계단부터 반복
- 태블릿에서 한 번 연 뒤 "홈 화면에 추가"하면 인터넷 없이도 실행됩니다.
- 최고기록 초기화: 처음 화면 왼쪽 위 "기록 초기화" 버튼 (또는 "제작: myoLab(산쌤)"을 3초 길게 누르기)

## 순위표

- TV 순위표: https://ys970425.github.io/yesan-entrybot-stairs/board/ (노트북을 TV에 연결 → 열기 → "전체 화면")
- 관리자: https://ys970425.github.io/yesan-entrybot-stairs/admin/ (Supabase에 설정한 관리자 비밀번호)
- 서버 설정: `supabase/setup.sql` 을 Supabase SQL Editor에서 실행 (비밀번호 바꿀 때도 다시 실행)
- 게임 시작 때 닉네임 입력 → 게임이 끝나면 기록 자동 전송 (인터넷이 끊기면 모아 두었다가 다시 보냄)
- 상: 1등 1명(1위) 3만원, 2등 2명(2~3위) 2만원, 3등 3명(4~6위) 1만원 — 6위까지 학교·학년·이름 입력, 밀려나면 자동 삭제. 행사 후 관리자 화면에서 전체 삭제
- 닉네임 입력 때 엔트리봇 색 11가지 중 선택 (게임·TV 시상식에 같은 색으로 나옴)
- TV 화면: 예산 e스포츠 한마당 시상식 (1~6위는 시상대, 7~10위는 구경꾼, 순위가 바뀌면 걸어서 자리 이동)

## 고치는 곳

- 난이도, 부스터, 배경 순서와 이름: `src/config.js`
- 파일을 고친 뒤 배포할 때는 `sw.js`의 `VERSION`을 올려야 태블릿에 새 버전이 반영됩니다.
